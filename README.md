# RetailIQ — E-commerce Sales and Customer Analytics

## Project Overview
RetailIQ is an end-to-end data analytics project focused on analyzing e-commerce sales, customer behavior, product performance, and operational efficiency.

## Tools and Technologies
- SQL — Data validation and business analysis
- Python — Data cleaning, exploratory data analysis, and feature engineering
- Pandas and NumPy — Data manipulation
- Matplotlib and Seaborn — Data visualization
- Power BI — Interactive dashboards

## Project Structure
- `data/` — Raw, cleaned, and processed datasets
- `notebooks/` — Data cleaning, EDA, and feature engineering notebooks
- `sql/` — Database schema, data validation, and business analysis queries
- `powerbi/` — Power BI dashboard file
- `reports/` — Business questions and analysis reports
- `src/` — Python source code
- `tests/` — Data validation tests

## Power BI Dashboard
The dashboard contains four pages:
1. Executive Overview
2. Sales & Product Analysis
3. Customer Analytics
4. Operations Analysis

## Key Business Areas
- Revenue and profit performance
- Product and category analysis
- Customer purchasing behavior
- Regional sales performance
- Delivery performance and returns
- Customer loyalty and repeat purchases

## Data Quality
SQL validation queries are included to check missing values, duplicate IDs, referential integrity, and financial consistency.

## How to Use
1. Review the SQL scripts in `sql/`.
2. Explore the notebooks in `notebooks/`.
3. Open `powerbi/RETAIL.pbix` in Power BI Desktop to explore the dashboards.
